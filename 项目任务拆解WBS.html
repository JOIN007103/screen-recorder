关键路径与排程约束

关键路径：阶段 0 技术验证 → 屏幕捕获 → 状态机集成 → 编码导出 → 回放 → 阶段 3 性能优化 → 兼容性 → 交付包。该路径决定总工期，任何一环延误都会顺延整体交付。

排程风险提示：① 阶段 0 技术验证若发现捕获或编码方案不可行，需启用回退方案，可能增加 3–5 人日；② 阶段 2 音画同步调优存在不确定性，是本 WBS 中最易超时的单项；③ 阶段 3 兼容性受机型矩阵规模影响，机型越多耗时越长。建议在每阶段出口设置一次排程复核。
