关键假设与决策冻结

以下 11 项决策已通过选择题逐项确认并冻结，构成后续全部规划工作的约束基线。

决策项最终结论对规划的影响
目标操作系统仅 Windows 10/11技术栈聚焦，捕获方案单一，工期可控
团队与工期1 人，22 周基准沿用里程碑估算，范围收敛后有望压缩
产品定位先个人自用，好用再内部分发阶段 3 先做免安装器交付，预留分发扩展
剪辑边界不含剪辑，仅录制 + 回放MVP 边界锁定
声音方案首版不录声音音频与音画同步模块移出 MVP，降为阶段 2
录制范围仅全屏窗口 / 区域 / 多屏列为后续增强
鼠标效果点击涟漪 + 光标高亮 + 鼠标轨迹三项全部纳入 MVP，效果渲染工作量上升
清晰度帧率1080p / 30fps与默认基线一致
导出格式H.264 + MP4兼容性目标达成，主流电脑与手机可播
性能目标流畅优先编码策略偏向低占用，画质适度妥协
文件时长不设上限，手动停止存储模块最简化

相对初始草案的关键变更

① 声音模块整体后移
  • MVP 由"含音频"变为"纯画面录制"
  • 音画同步风险从阶段 1 推迟到阶段 2
  • 捕获链路简化
② 鼠标效果范围扩大
  • 由默认 1 项增至 3 项
  • 效果渲染模块工作量上升
  • 轨迹逐帧绘制成为新风险点
③ 产品定位分两阶段
  • 阶段 3 不引入安装器与授权
  • 仅保留最简交付
  • 转内部分发时再补打包能力
④ 工期出现余量
  • 阶段 1 由 6 周压缩至约 4–5 周
  • 整体 22 周收敛至约 18–20 周
  • 需以技术验证结果实测校准
待你在后续确认的收尾事项：阶段 3 的交付形式（绿色免安装版 / 安装器）与内部分发方案的取舍，可在 MVP 验证"好用"之后再定，不阻塞阶段 0–2 推进。

核心功能范围与模块划分

系统按"交互控制 → 数据采集 → 处理编码 → 输出回放"四层组织，共 13 个核心模块，形成一条自顶向下的数据流水线。MVP 与增强阶段的差异体现在每层内模块的深度，而非层级结构本身。

模块职责说明

模块职责阶段
主界面 / 悬浮控制条参数设置、录制入口、开始/暂停/停止操作面板MVP
录制状态机管理空闲/录制/暂停/保存的状态切换，保证闭环正确MVP
屏幕捕获Windows 全屏画面采集，1080p/30fpsMVP
鼠标事件 + 效果渲染点击位置捕获，涟漪、光标高亮、轨迹三项效果叠加MVP
音视频编码 / MP4 封装H.264 硬件编码优先、流畅优先策略，MP4 封装MVP

音频采集 / 混音同步系统音+麦克风采集、混音、音画时间戳对齐阶段 2

分阶段开发计划与里程碑

工期以 1 名全职开发为估算基准，范围收敛后整体约 18–20 周。周数为排程参考，需以阶段 0 技术验证结果实测校准。

阶段 0
约 1 周
决策冻结与技术验证（Pre-MVP）
决策已全部确认，本阶段聚焦验证 Windows 全屏捕获 + H.264 硬件编码 单一链路可行性，定义可量化验收基线。出口条件：最小链路跑通。
阶段 1
约 4–5 周
MVP 最小可用版本
全屏捕获（1080p/30fps）+ 录制控制闭环 + 三项鼠标效果 + H.264/MP4 导出 + 基础回放 + 悬浮控制条。验收点：录一段操作流程 → 保存为通用 MP4 → 回放确认，端到端无阻断缺陷。
阶段 2
约 8 周
功能增强
音频采集与混录、音画同步、窗口/区域录制、按键提示、参数配置。验收点：音画同步偏差在可接受阈值内，多模式录制稳定，配置生效。
阶段 3
约 5–6 周
体验优化与分发
多屏录制、性能与内存优化、跨机型兼容性、最简交付包。安装器与分发作为可选扩展（待"好用"后确认）。验收点：目标机型矩阵通过兼容性与性能测试。

测试重点

按阶段递进，MVP 阶段先守住"录制闭环"这条主线，音画相关测试随阶段 2 音频模块纳入后展开。

测试类别重点内容阶段
功能闭环开始/暂停/停止/保存状态切换正确，暂停不丢帧、停止可落盘阶段 1
输出兼容导出 MP4 在 Windows 内置播放器、主流手机、网页均可正常播放阶段 1
鼠标效果涟漪/高亮/轨迹与光标位置对齐，轨迹绘制不明显拖累帧率阶段 1
性能录制期间 CPU/GPU 占用、帧率稳定性、长时间录制内存无泄漏阶段 1 起
音画同步系统音与麦克风混录后，音画时间戳偏差在可接受阈值内阶段 2
兼容性不同分辨率、多显示器、不同 Windows 版本与显卡环境阶段 2–3
异常场景录制中切换窗口、弹窗、休眠恢复，文件不损坏全阶段
6

潜在风险与应对

风险影响应对方式
全屏捕获在部分显卡/全屏应用下黑屏或掉帧高阶段 0 先做技术验证；准备捕获方案备选（硬件加速捕获回退到 GDI/BitBlt）
硬件编码不受支持或质量不佳中设置软编码回退路径，画质与性能可配置权衡
鼠标轨迹逐帧绘制影响帧率（新增风险）中限制轨迹长度与采样频率，阶段 1 专项测试帧率
音画不同步（阶段 2 起）中统一时间基准，混录前对齐采样时钟，阶段 2 专项测试
不设时长上限导致磁盘占满或文件损坏中虽按决策不设硬上限，仍建议加入磁盘空间预警提示
MP4 在个别设备播放兼容问题低固定使用 H.264 + MP4 通用组合，避免冷门编码
