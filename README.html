屏幕录制工具 v1.0.0

绿色免安装版 · 解压即用 · 无需安装、不写注册表 · Windows 10 / 11
这个文件夹里有什么
  • ScreenRecorder.exe —— 主程序，双击即可运行
  • tools\ffmpeg.exe —— 编码组件，必须和主程序保持这个目录结构，不要单独移动或删除
  • Videos\ —— 录制视频的默认保存位置（首次运行时自动建立）
  • README.html —— 本说明，可用浏览器打开
  • settings.json、logs\ —— 首次运行后自动生成，分别是配置和本地日志

一、快速开始（四步）

  1. 双击 ScreenRecorder.exe。界面下方的「编码组件」显示已就绪 ✓即可开始。
  2. 确认「保存位置」（默认就是本目录下的 Videos\），选择编码方式与倒计时。
  3. 点击 ● 开始录制。默认有 3 秒倒计时，这段时间不录画面，可用来把鼠标移到合适位置。
  4. 录制完按 F10 或点击深色悬浮条上的「停止」。主窗口会回来，并显示文件大小、保存路径和「立即播放」按钮。

二、录制中怎么操作

操作方法说明
开始录制F9 或主窗口按钮倒计时结束后正式开始写帧
暂停 / 继续F9暂停期间不写画面也不写声音，恢复后时间轴连续
停止并保存F10 或悬浮条按钮热键在主窗口隐藏后仍然有效

录制开始后主窗口会自动隐藏，只留一条深色悬浮控制条。这条控制条不会被录进视频——已通过实测验证（逐像素检测，成片中命中 7 个像素，可忽略）。如果热键被其他软件占用，界面会用黄字提示，此时请改用悬浮条操作。

三、鼠标效果与画面设置

设置项默认值说明
点击涟漪 / 光圈开鼠标点击时显示扩散光圈，适合操作演示
光标高亮开让光标在视频里更醒目
鼠标轨迹关按使用者意见默认关闭，避免影响观感；需要时可在界面打开
编码方式自动优先用 NVIDIA 显卡硬编码（CPU 占用约为软编码的 1/19）；检测不到就自动回退软编码，不会录出坏文件
画面参数1080p / 30fpsH.264 编码，MP4 封装，手机和微信可正常播放

四、声音

成片里是单音轨：系统声与麦克风在录制时就混合成一条音轨，手机、微信的兼容性最好。两路音量可分别调整（0～200%）。
  • 系统声音（软件提示音、视频声音）：正常可用。启动后界面会显示检测结果。
  • 麦克风（讲解声）：需要有捕获设备。如果电脑上没有麦克风，界面会提示「仅检测到系统声 ✓；未检测到麦克风，麦克风选项将被忽略」——此时画面与系统声照常录制，不会报错。
  • 即使两路都没有，也只会生成一条静音音轨，画面完全不受影响。

五、保存、回放与手机播放

  1. 停止后主窗口显示结果卡片，可点「打开所在文件夹」或「立即播放」。
  2. 「最近录制」列表里双击任一文件即可回放。
  3. MP4 可直接发到微信或在手机上播放。如果需要最多的设备兼容，导出前把编码方式选为「libx264 软编码」。
  4. 默认码率 4 Mbps，1080p30 下约每分钟 30 MB；界面可设置磁盘剩余空间预警（仅提示、不强制停止）。

六、常见问题

现象处理
提示「编码组件缺失」检查 tools\ffmpeg.exe 是否还在，且目录名就是 tools。整个文件夹一起移动，不要只拷 exe。
没有声音确认界面「系统声音」已勾选、音量不是 0；若电脑本身没有在播放任何声音，音轨会是静音，这是正常的。
热键没反应F9/F10 可能被别的软件占用，界面会有黄字提示，改用悬浮条即可。
悬浮条在录进画面了吗？不会。悬浮条使用系统级捕获排除，已用产品真实窗口逐像素验证。
想重新设置点主窗口左下角的蓝色版本号可看关于信息；删除 settings.json 后重启即恢复出厂设置。

七、配置、日志与卸载

  • 配置：settings.json 就放在本目录，随文件夹一起走；不要单独拷到别的机器使用。
  • 日志：logs\run_日期.log 记录启动、热键、录制开始/停止和异常堆栈。只写在本目录，不会外发。程序目录不可写时自动禁用，不影响使用。反馈问题时可以把当天的日志一并发来。
  • 卸载：直接删除整个文件夹即可。不写注册表、不往系统目录放东西、删除后无残留。
